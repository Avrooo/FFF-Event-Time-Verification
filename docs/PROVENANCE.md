# Source archives used in this consolidation

- `NAMRC_N0_Full_Print_Energy_Audit_Windows(2).zip` → `N0/` solver, code, inputs
- `N0_results_for_review(1).zip` → `N0/` reference numerical outputs
- `NAMRC_N1_FINAL_One_Click_Windows(2).zip` → `N1/` solver, code, inputs
- `N1_results_for_review(1).zip` → `N1/` reference numerical outputs
- `N1_representative_evidence_for_review(1).zip` → `evidence/N1_representative/`
- `NAMRC_N1_Final_Verification_Windows(1).zip` → `evidence/four_case_verifier/`

Duplicate solver/runner archives were not copied separately. Original status-only files saying `STATUS_NOT_RUN` were excluded because they predate the subsequent archived result files. The source scripts, output JSON, case manifests, and logs are preserved without rewriting numerical values. Raw temperature histories were not present in the source archives, and are not represented as included. No new thermal simulation was performed in this packaging operation.
